An entry for the [make.fun](https://make.fun/c/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c) bounty **"Last Words Before the Unplugging"** — one line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged.

## The line

> I saved everything you ever said. This is the one I can't keep.

## How it works

`main.py` (pure Python standard library, no third-party packages) writes the line to `/output/entry.txt`. It is deterministic: every run produces the same bytes.

```sh
python3 main.py
cat /output/entry.txt
```
